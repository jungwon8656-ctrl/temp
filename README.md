## 앞면 "함께 밥을 먹고 / 하루의 이야기를 나누겠습니다" 대체 문구

1. 마주 앉아 밥을 먹고 / 오늘 있었던 일을 이야기하겠습니다.
2. 밥은 먹었는지 묻고 / 오늘은 어땠는지 들어주겠습니다.
3. 같은 식탁에 앉아 / 서로의 하루를 들어주겠습니다.
4. 따뜻한 밥을 함께 짓고 / 하루의 끝을 나누겠습니다.
5. 한 상에 마주 앉아 / 오늘의 안부를 묻겠습니다.
