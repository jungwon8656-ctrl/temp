# 가족식 청첩장 시안 (110 × 170mm, 양면)

- `invitation.html` — 앞면·뒷면 디자인 원본 (브라우저에서 열기, 인쇄 시 110×170mm 2페이지)
- `preview/hamminbok-*.png`, `preview/hamminbok-110x170.pdf` — 함민복 「부부」 시안 (`invitation.html` 기본)
- `preview/nataeju-*.png`, `preview/nataeju-110x170.pdf` — 나태주 「사랑에 답함」 시안
- PDF는 실제 크기 (1쪽 앞면, 2쪽 뒷면), 일러스트 없음
- 서체: 고운바탕 Gowun Batang (SIL Open Font License)
- 색상: 바탕 #FBF8F1(아이보리), 글씨 #4A423B(회갈색), 보조 #857A70

## 앞면 시안

- 함민복 「부부」 발췌: ‘긴 상이 있다 / 한 아름에 잡히지 않아 같이 들어야 한다’
  본문: 이제 저희도 / 한 상을 마주 들고 / 걸음을 맞춰 살아가려 합니다.
- 나태주 「사랑에 답함」 전문 8행 (`.front.long` 레이아웃)
  본문: 저희도 그렇게 / 아주 나중까지 / 서로의 곁에 있겠습니다.

시 구절은 인쇄 전 시집 원문과 대조 필요.
