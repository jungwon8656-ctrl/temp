## 앞면 본문 통합 문구 (기존 두 문단을 하나로)

현재 시안에는 2번이 들어가 있습니다.

1. 매일 마주 앉아 밥을 먹듯 / 평범한 하루를 함께 보내며 / 서로에게 없어서는 안 될 사람이 되겠습니다.
2. 밥은 먹었는지, 오늘은 어땠는지 / 서로의 안부를 물으며 / 밥처럼 늘 곁에 있는 사람이 되겠습니다.
3. 한 상에 마주 앉아 하루를 나누고 / 매일 먹는 밥처럼 / 늘 곁에 있는 사람으로 살겠습니다.
4. 날마다 같은 밥을 먹고 / 같은 하루를 살아가며 / 서로를 살게 하는 힘이 되겠습니다.
5. 특별하지 않아도 괜찮은 / 매일의 밥처럼 / 서로의 하루를 든든히 채워주겠습니다.
