- 시: 이문재 「농담」 1연 (시집 『제국호텔』, 문학동네, 2004)
- 본문 5번: 아름다운 것 앞에서 / 늘 서로를 떠올리던 저희가 / 이제 함께 살아가려 합니다.
- 본문 8번: 서로에게 그런 얼굴이 되어 / 아름다운 날도, 평범한 날도 / 함께 보려 합니다.

시 구절은 인쇄 전 시집 원문과 대조 필요.
