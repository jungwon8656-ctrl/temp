# 가족식 청첩장 시안 (110 × 170mm, 양면)

- `invitation.html` — 앞면·뒷면 디자인 원본 (브라우저에서 열기, 인쇄 시 110×170mm 2페이지)
- `preview/final-A-*.png`, `preview/final-A-110x170.pdf` — 최종안 A (`invitation.html` 기본 문구)
- `preview/final-D-*.png`, `preview/final-D-110x170.pdf` — 최종안 D
- PDF는 실제 크기 (1쪽 앞면, 2쪽 뒷면)

## 앞면 본문 최종 후보

- A (기본): 당신의 이름을 지어 며칠을 살았듯 / 이제는 함께 밥을 지으며 / 매일을 살겠습니다.
- D: 이름 하나에 기대어 / 며칠을 건넜던 마음으로 / 이제는 한 그릇의 밥처럼 / 서로 곁에 있겠습니다.
