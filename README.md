# 가족식 청첩장 시안 (110 × 170mm, 양면)

- `invitation.html` — 앞면·뒷면 디자인 원본 (브라우저에서 열기, 인쇄 시 110×170mm 2페이지)
- `preview/option-1-*.png`, `preview/option-1-110x170.pdf` — 문구 1안 (`invitation.html` 기본)
- `preview/option-2-*.png`, `preview/option-2-110x170.pdf` — 문구 2안
- PDF는 실제 크기 (1쪽 앞면, 2쪽 뒷면), 일러스트 없음

## 앞면 본문 후보

- 1안 (기본): 이제 저희도 / 서로의 이름으로 / 평생을 살아가려 합니다.
- 2안: 서로의 이름만으로도 / 평생을 살아갈 수 있는 / 그런 사이가 되겠습니다.
