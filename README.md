# 가족식 청첩장 시안 (105 × 157mm, 양면)

- `invitation.html` — 앞면·뒷면 디자인 원본 (브라우저에서 열기, 인쇄 시 105×157mm 2페이지)
- `preview/final-front.png`, `preview/final-back.png`, `preview/final-front-back.png` — 최종 미리보기
- `paper-samples.html`, `preview/paper-samples.png` — 비도공 고급지 5종 비교 (화면용 근사치)
- 서체: 고운바탕 Gowun Batang (SIL Open Font License)
- 색상: 바탕 #FBF8F1(아이보리, 화면용), 글씨 #3A322C(짙은 회갈색), 보조 #6A6057 — 인쇄 대비를 위해 진하게 조정

## 앞면

- 시: 이문재 「농담」 1연 (시집 『제국호텔』, 문학동네, 2004) — 표기: 따옴표 없이, 출처 "이문재의 「농담」 중"
- 글자 크기: 시·본문·뒷면 인사말·날짜 10.5pt / 출처 7.5pt / 가족 표기 기존 유지
- 본문 (최종): 아름다운 것 앞에서 / 늘 서로를 떠올리던 저희가 / 이제 함께 살아가려 합니다.

시 구절은 인쇄 전 시집 원문과 대조 필요.

## 인쇄용 파일 (재단 105 × 157mm / 작업 107 × 159mm, 도련 1mm)

- `print/invitation-print-107x159-bleed1mm.pdf` — 인쇄소 전달용 벡터 PDF (1쪽 앞면, 2쪽 뒷면, TrimBox 설정, 배경 없음)
- `print/jpg/` — 편집기 업로드용 JPG (흰 바탕)
  - 1000dpi: 4213 × 6260px (편집기 7000px 제한 이내) / 300dpi: 1264 × 1878px
- 주문 사양: 아르떼 내추럴화이트 310g(가능 시), 양면 인쇄, 후가공 없음
- 봉투: 110 × 160mm 반투명 봉투 (카드 105 × 157mm, 좌우 여유 각 2.5mm)

## 양가 부모님용 청첩장 (같은 규격: 재단 105 × 157mm / 작업 107 × 159mm)

- `parents.html` — 디자인 원본 (앞면: 혼주 인사말, 뒷면: 신랑·신부 이름, 날짜, 혼주 서명)
- `print/parents-print-107x159-bleed1mm.pdf` — 제출용 벡터 PDF (1쪽 앞면, 2쪽 뒷면)
- `print/jpg-parents/` — 예비용 JPG (300dpi / 1000dpi)
- `preview/parents-*.png` — 미리보기
- 문구 손질: "두사람" → "두 사람"(띄어쓰기), 마지막 문장에 마침표 추가. "[혼주 서명]"은 안내용 표시로 보고 인쇄하지 않음

## 저녁 식사 감사 슬라이드쇼 (프로젝터용)

- `slideshow.html` — 인사말 → 스튜디오 사진 자동 전환 → 감사 화면 순서로 반복
- 사용: 크롬으로 열기 → 사진 넣기 → [전체화면으로 시작]
  - 자동: `slideshow.html` 옆 `photos/` 폴더에 `01.jpg`, `02.jpg` … 번호 이름으로 넣어 두면 열 때 바로 불러옴
  - 직접: [폴더 선택]으로 사진 폴더 지정, [사진 선택], 또는 화면에 끌어다 놓기
- 배경: 아이보리(기본) / 모카 — 설정창 또는 T 키로 전환
  - 사진은 파일 이름 순서(01, 02 …)로 재생, 무작위 선택 가능. 사진당 4~15초
  - 사진은 브라우저 안에서만 열리고 어디에도 업로드되지 않음
- 단축키: 스페이스 멈춤/재생 · ←/→(프레젠터 리모컨 가능) 이전/다음 · M 인사말 화면에서 멈춤 · C 이름 표기 · T 배경 · F 전체화면 · S 설정창
- 인사말 문구: 파일 안 `tpl-intro`, `tpl-outro` 부분에서 수정
- 인터넷 없이도 `fonts/` 폴더의 고운바탕으로 표시 (`slideshow.html`과 `fonts/`를 같은 위치에 두기)
